HTML 资料：直接阅读与修改

返回总目录

这是一套直接维护的静态 HTML 资料。正文就在各页面中，后续可以让 AI 修改 HTML、样式和交互；无需 Python、Node、依赖安装或编译步骤。

阅读

直接打开仓库根目录的 index.html。打开本地文件就能使用主题导航、页内目录、搜索、图片和打印样式。

按 / 搜索页面标题、摘要和关键词，例如“租约”“取消”“P7”。页面内查找具体原句可使用浏览器的查找功能。窄屏下点击“目录”展开侧栏。

让 AI 修改什么

需要调整直接修改的位置
教材正文、表格、公式、页内目录对应的 HTML 页面
共同排版与配色assets/site.css
搜索、菜单和图表交互assets/site.js
搜索标题、摘要、关键词与地址assets/search-index.js 中对应的一条记录
新增章节或移动页面HTML、主题入口、侧栏及相关链接；同步搜索记录

例如：“直接修改 KV 存储章节的 HTML，增加租约到期的失败时序图，并同步目录和搜索关键词。” 修改后刷新浏览器即可查看。

图表与公式

主线设计图使用 SVG，可以直接修改。原有 Mermaid 图源保留在 HTML 中，由浏览器内的本地 JavaScript 显示；修改图源后刷新即可。数学公式使用 MathML，可直接编辑相应标签。

Mermaid 10.9.3 已随资料保存，许可证位于 assets/MERMAID-LICENSE.txt。图片、样式和搜索无需访问在线 CDN。

文件结构与检查

八个主题目录只放 HTML、SVG 和实验脚本；assets/ 放共享样式、脚本、搜索目录和 Mermaid。旧 Markdown/RST、生成快照与构建脚本已经删除，历史版本可从 Git 找回。

修改后检查内容与版本依据、页内锚点、跨页链接、搜索入口，以及宽表、代码和图表的实际显示。HTML 中的能力要求仍以专家总纲为主，覆盖边界见审阅报告。
